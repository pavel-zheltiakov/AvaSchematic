Symbols.SymbolBuilder

public sealed class Symbols.SymbolBuilder

Fluent builder for SymbolDefinition. Style calls such as SymbolBuilder.Filled apply to the primitive added last, so a symbol reads top to bottom like a drawing script.

Symbols.SymbolBuilder Pin(string key, double tipX, double tipY, Model.PortSide side, double length = 10.0, string name = null, string number = null, Model.PortKind kind = Model.PortKind.Passive)

Adds an electronic pin: draws the pin line from the body edge outwards and registers the port at its tip, which is where wires attach.

key

Port key, usually the pin number or signal name.

tipX

Tip X in definition space - keep it on the grid pitch.

tipY

Tip Y in definition space.

side

Outward direction of the pin.

length

Pin line length drawn inwards from the tip.

name

Signal name; when given the pin name is shown by default.

number

Physical pin number; when given it is shown by default.

kind

Electrical meaning of the pin.
