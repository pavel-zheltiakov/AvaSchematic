Documentation · Laying out the lines

Routing.SegmentEditor

public static class Routing.SegmentEditor

Reshaping a line by one segment at a time, the way every diagram and EDA editor does it: grab a run and slide it sideways, and the two runs either side stretch to follow. Segments touching a pinned end grow a jog rather than dragging the pin, so a wire never comes off a pin sideways.

Methods

static void Apply(Model.SchematicConnection connection, IReadOnlyList<Point> polyline)

Writes a polyline back, moving whichever ends are free and keeping the rest as bends.

Every hand edit stores its shape through here, so this is the one place that can promise the stored shape never draws itself twice: a run that ended up laid back over one the line has already covered is removed on the way in, whatever produced it.

static IReadOnlyList<Point> GetPolyline(Model.SchematicConnection connection)

The line as an editable polyline: resolved start, waypoints, resolved end.

static bool Materialize(Model.SchematicConnection connection)

Freezes the current automatic route into explicit waypoints and switches the line to the matching manual mode, so hand edits survive the next re-route.

static IReadOnlyList<Point> MoveCorner(IReadOnlyList<Point> polyline, int index, Point target, Routing.SegmentMoveOptions options)

Moves one corner of an orthogonal line, keeping it orthogonal.

A bend is where two runs meet, so moving it is moving both of them: the run arriving slides sideways to the new position and the run leaving slides sideways to it as well. Setting the bend to the pointer and leaving the neighbours where they were is the other way to do it, and it is wrong - it makes two diagonal steps, which the router then has to turn back into right angles by guessing where the corners go, and one of those guesses draws the wire back along the run it just came down.

An end that cannot move pins the axis it is on: a bend next to an attached pin slides along the pin's own direction and no further.

static IReadOnlyList<Point> MoveSegment(IReadOnlyList<Point> polyline, int index, Point target, Routing.SegmentMoveOptions options, out int movedIndex)

Slides segment index sideways so it passes through target. The neighbouring runs stretch to keep the line continuous; pinned ends grow a jog. Returns a new polyline and leaves the input untouched, so a drag can always recompute from the original.

static int NearestPoint(IReadOnlyList<Point> polyline, Point world)

The point of a polyline nearest a world position, or -1 when it has none.

static Routing.SegmentMoveOptions OptionsFor(Model.SchematicConnection connection, double segmentLength)

Options matching a connection's document, ends and clearance.

static void Simplify(Model.SchematicConnection connection)

Drops the redundant bends, and the retraces, a drag may have left behind.
