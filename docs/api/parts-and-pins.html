2 · Parts and pins

A part on the sheet is a placement of a drawing that lives somewhere else. This chapter is about where those drawings come from, how to put one down, how to turn it, and what the little bits of text beside it are.

A symbol is the drawing; a node is one of them on the sheet

A SymbolDefinition is the resistor: the two leads, the rectangle, the two pins, and the fact that its designator starts with R. There is exactly one of those in the library no matter how many resistors your circuit has.

A SchematicNode is this resistor: at this spot, turned this way, called R7, worth 10k. Ten thousand resistors on a sheet are ten thousand small nodes pointing at one drawing, which is why a big sheet stays cheap.

The library

SymbolLibrary.CreateDefault() hands you everything built in. The names are constants, so you never type a string and hope: 

var library = SymbolLibrary.CreateDefault();

Symbols.Basic.RoundedRectangle   // boxes, ellipses, arrows, callouts
Symbols.Flow.Decision            // the flowchart set
Symbols.Arch.Database            // services, queues, actors, boundaries
Symbols.Electric.ResistorIEC     // resistors, capacitors, transistors, chips, power
Symbols.Electric.LED
Symbols.Electric.GND
Symbols.Mindmap.Round            // a second name for Basic.Capsule

A key is Group.Name, and the group is what the symbol is for rather than which class draws it - which is how anyone looks one up. The value of Symbols.Electric.LED is the string "Electric.LED", so a document you open in a text editor says what it is made of.

The mindmap names are a second name for shapes that already exist: a bubble is a capsule, and drawing it twice would be two things to keep in step. library.Alias(name, key) is how you do the same for your own.

You can also make your own library, or add to this one - that is chapter 6.

Placing a part

// By pin: the pin named "1" lands exactly on (0, 0).
var r1 = document.AddNodeAtPin(Symbols.Electric.ResistorIEC, "1", new Point(0, 0));

// Turned a quarter turn as it is placed - the pin still lands on the point.
var c1 = document.AddNodeAtPin(Symbols.Electric.Capacitor, "1", new Point(0, 60), rotation: 90);

// By box, for a diagram shape you are about to caption.
var box = document.AddNode(Symbols.Arch.Service, new Point(300, 0), "API gateway");

Pins have names, and sometimes numbers

Every pin has a key - the short string you wire with. On a resistor they are "1" and "2"; on a transistor "B", "C", "E"; on a chip built from a pin list they are "L0", "R3" and so on. A pin can also carry a name shown inside the part (VDD, NRST) and a number shown outside it, which is the physical leg on the package. 

foreach (var pin in r1.Ports)
    Console.WriteLine($"{pin.Key} at {pin.WorldPosition}");

WorldPosition is where the pin is right now, after the part has been moved, turned and mirrored. You never have to work that out yourself.

Turning and mirroring

Set Rotation in degrees, or ask the control to turn what is selected: 

r1.Rotation = 90;                       // straight on the model
r1.Mirror   = MirrorMode.Horizontal;      // flipped left-to-right

View.RotateSelection();                   // one step, whatever the rulebook says a step is
View.RotateSelection(45);                 // or an exact angle

A schematic is drawn on right angles, so the rulebook's RotationStep is 90 by default and every turn - the button, the keyboard, the rotate handle - lands on a multiple of it. A diagram that wants forty-five degree parts sets the step to 45 and gets exactly that. Nothing ever leaves a part at a crooked seventeen degrees by accident.

Turning a part turns its pins with it, and every wire attached to them is laid out again on the spot.

Designator, value and other fields

The little words beside a part are attributes. Two of them have shortcuts because every schematic has them: 

r1.Designator = "R1";      // which one this is
r1.Value      = "10k";     // what it is worth

r1["Footprint"] = "0805";  // anything else you need, by name

Each field remembers where it sits relative to the part, so it travels with it: move the resistor and its "10k" moves too; turn the resistor and the label swings round with it but stays the right way up to read. On screen a field can be picked and dragged on its own - see chapter 5.
