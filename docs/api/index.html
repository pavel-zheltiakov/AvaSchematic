Controls.WheelBehaviorHow the mouse wheel behaves over the surface.

The drawing

A sheet is a list of items: parts, the lines between them, and the dots where lines join.

Model.SchematicDocumentThe drawing: a flat list of nodes, connections and junctions plus the symbol library they resolve against.
Model.SchematicItemBase class for everything that lives in a SchematicDocument: nodes, connections and junctions.
Model.SchematicNodeAn instance of a SymbolDefinition placed in the document: a mindmap bubble, an architecture box, a flowchart decision or a resistor.
Model.SchematicConnectionA line between two endpoints: a mindmap branch, an architecture arrow, a UML relation or an electrical wire.
Model.SchematicJunctionAn explicit connection point shared by several lines.
Model.ConnectionEndpointOne end of a connection.
Model.PortA connection point on a node instance.
Model.SchematicAttributeA named piece of text attached to a node - the designator "R7", the value "10k", a footprint, a stereotype on a UML box, or any host defined metadata.
Model.AttributeKeysWell known attribute keys understood by the built-in tooling.
Model.ItemStylePer item appearance overrides.
Model.SchematicLayersWell known layer names.
Model.SchematicClonerDeep-copies a set of items while rewiring the connections between them.
Model.SchematicItemsChangedEventArgsRaised when items are added to or removed from a document.

Parts

A symbol is a drawing plus a pin list. A library is a box of them, by name.

Symbols.SymbolLibraryA named set of SymbolDefinitions.
Symbols.SymbolDefinitionA reusable shape: geometry, pins and default fields.
Symbols.SymbolBuilderFluent builder for SymbolDefinition.
Symbols.PortDefinitionA pin as declared by a library symbol.
Symbols.Libraries.ElectronicSymbolsElectronic schematic symbols.
Symbols.Libraries.BasicShapesGeneral purpose shapes for mindmaps and free-form drawings.
Symbols.Libraries.FlowchartSymbolsClassic flowchart vocabulary, stretchable and defined in a 100 x 60 box.
Symbols.Libraries.ArchitectureSymbolsSoftware architecture and UML vocabulary: services, stores, queues, actors and the UML boxes used on class and component diagrams.

What a symbol is drawn from

Lines, boxes, arcs and text in the symbol's own coordinates, baked into geometry when drawn.

Symbols.SymbolPrimitiveOne drawing element of a symbol, expressed in symbol definition space.
Symbols.SymbolLineStraight segment.
Symbols.SymbolPolylineOpen or closed polyline; the basis of arrows, zig-zag resistors and flowchart shapes.
Symbols.SymbolRectangleAxis aligned rectangle in definition space, optionally with rounded corners.
Symbols.SymbolEllipseEllipse or circle, emitted as four cubic segments so any affine matrix bakes exactly.
Symbols.SymbolArcElliptical arc given by centre, radii and angles in degrees (0 = +X, clockwise positive).
Symbols.SymbolPathArbitrary SVG path data, flattened once and then baked like every other primitive.
Symbols.SymbolTextStatic text baked into the symbol (pin names, "+"/"-" on an op-amp, block captions).
Symbols.GeometryUtilPath helpers shared by the primitives.

Laying out the lines

How a wire gets from one pin to another without sitting on another wire or crossing a part.

Routing.IConnectionRouterTurns a RouteRequest into a drawable path.
Routing.OrthogonalRouterManhattan router.
Routing.DirectRouterStraight line between the two ends; waypoints are ignored.
Routing.CurvedRouterCubic bezier honouring the port normals, which is what mindmaps and "organic" architecture diagrams want.
Routing.PolylineRouterStraight segments through every waypoint.
Routing.RouteRequestEverything a router needs to lay out one connection.
Routing.RouteResultA routed connection path.
Routing.RouteKindShape of the point list produced by a router.
Routing.RouteUtilPolyline clean-up helpers shared by the routers.
Routing.SegmentEditorReshaping a line by one segment at a time, the way every diagram and EDA editor does it: grab a run and slide it sideways, and the two runs either side stretch to follow.
Routing.SegmentMoveOptionsHow a single segment is allowed to move.
Routing.WireOccupancyThe lanes already taken by wires on the sheet.

Mouse and keyboard

Tools are small state machines; the hit tester decides what the pointer is over.

Interaction.IToolA modal interaction mode: select, wire, place a part, pan.
Interaction.ToolBaseConvenience base with no-op handlers and the usual helpers.
Interaction.SelectToolThe default tool: pick, rubber band, move, resize, rotate, reshape a line and re-wire its ends.
Interaction.WireToolDraws connections.
Interaction.PlaceToolPlaces instances of one symbol.
Interaction.PanToolDrag to scroll.
Interaction.ToolPointerEventArgsPointer information already converted to world space and snapped to the grid.
Interaction.SchematicHitTesterPicks the top-most thing under a world point.
Interaction.HitTestResultOutcome of a pick at a world point.
Interaction.HitKindWhat kind of thing the pointer landed on.
Interaction.HitTestFilterWhich item classes a pick should consider.
Interaction.ConnectionToolsShared endpoint attachment logic used by the wiring tool and by re-wiring in select mode.
Model.ResizeHandleHandle identifiers used by the selection adorner.

Rendering.DrawingResourcesPen, brush and typeface cache.
