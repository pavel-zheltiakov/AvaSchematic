Model.SchematicNode

public sealed class Model.SchematicNode : Model.SchematicItem

An instance of a SymbolDefinition placed in the document: a mindmap bubble, an architecture box, a flowchart decision or a resistor. Everything a node needs to be either of those lives in the symbol - the node itself only carries placement, ports and fields.

Rect GetAttributeBounds(Model.SchematicAttribute attribute)

World box of one attribute label. Its anchor lives in symbol definition space, so the box travels with the part - moved, turned or mirrored - which is exactly what a field dragged away from its symbol has to keep doing.

Point GetBoundaryPoint(Point towardWorld, out Vector worldNormal)
