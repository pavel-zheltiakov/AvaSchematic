Controls.SchematicView

public class Controls.SchematicView : Controls.Control

The schematic / diagram surface. It owns a SchematicDocument, a viewport, a tool and a selection, and paints everything itself in immediate mode.

One control covers mindmaps, architecture drawings and electronic schematics because all three reduce to the same primitives: shapes carrying ports, lines joining ports, junctions where lines meet, and text fields attached to shapes. What differs between them is the symbol library, the routing mode and which decorations SchematicView.RenderOptions turns on.
